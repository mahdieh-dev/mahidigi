# mahidigi

A full-stack multi-vendor e-commerce marketplace inspired by Digikala, built with Next.js, Expo, and modern full-stack architecture.

> Built by **MahiDev** as a real-world portfolio and educational project.

---

## About

**mahidigi** is a production-focused multi-vendor e-commerce marketplace project inspired by the experience and architecture of large-scale platforms like Digikala.

The goal of this project is to build a complete marketplace ecosystem from scratch, including a modern web storefront, mobile application, vendor dashboard, admin panel, authentication, product management, cart, checkout, order management, security, and scalable architecture.

This project is currently in active development and is being built publicly as a real-world full-stack project.

---

## Project Goals

The main goal of **mahidigi** is to create a complete, real-world marketplace platform that demonstrates how modern e-commerce applications are designed and developed.

This project focuses on:

- Building a real multi-vendor marketplace
- Creating both web and mobile applications
- Designing a clean and scalable architecture
- Implementing secure authentication and authorization
- Managing products, categories, vendors, carts, orders, and users
- Creating vendor and admin dashboards
- Following modern full-stack development practices
- Writing maintainable, production-ready code
- Turning a complex product idea into a real working application
